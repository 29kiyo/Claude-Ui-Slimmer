# Claude UI Slimmer

claude.ai (Web版) の以下2つの不満を解消するChrome/Edge拡張機能です。

1. ファイル添付時のサムネイルが大きすぎて出力内容が見えなくなる問題
2. チャット欄に長文を貼り付けると入力欄が大きく伸び、出力内容が見えなくなる問題

添付ファイルのサイズと入力欄の最大高さを、ツールバーのポップアップからリアルタイムに調整できます。

## インストール方法(Chrome / Edge共通)

1. このリポジトリをclone、またはZIPでダウンロードして展開する
2. ブラウザで拡張機能管理ページを開く
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
3. 右上(Edgeは左側/右下)の「デベロッパーモード」/「開発者モード」をONにする
4. 「パッケージ化されていない拡張機能を読み込む」(Chrome) / 「展開して読み込み」(Edge) をクリックし、
   このリポジトリのフォルダを選択する

## 使い方

1. ツールバーに拡張機能のアイコンをピン留めする
2. claude.aiを開いた状態でアイコンをクリックし、ポップアップを開く
3. 「添付ファイルサイズ」「入力欄の最大高さ」のスライダーまたは数値入力で調整
   - 変更は即座にclaude.aiのページに反映されます
   - 設定はブラウザに保存され、次回claude.aiを開いたときも維持されます
4. 「リセット」ボタンでデフォルト値(120px / 200px)に戻せます

## 開発者向け

開発時のセットアップ、フェーズごとの設計は `docs/`(リポジトリには含まれません)を参照してください。

配布用パッケージの作成は GitHub Actions で行います。GitHubの「Actions」タブ →
「Build and Release」ワークフロー → 「Run workflow」から、リリースしたいタグ
(例: `v1.0.0`)を入力して実行すると、そのタグでGitHub Releaseが自動作成され、
`manifest.json`のversionをそのタグに合わせたzipが添付されます。
